# Zen Realty

## Project Overview

Zen Realty is a premium real estate platform designed to help clients discover and invest in luxury properties. This web application is built with modern technologies to deliver a seamless user experience.

## Getting Started

### Prerequisites

- Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

## Technologies Used

- [React](https://react.dev/) - A JavaScript library for building user interfaces
- [TypeScript](https://www.typescriptlang.org/) - TypeScript is a strongly typed programming language that builds on JavaScript
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework for rapidly building custom designs
- [shadcn/ui](https://ui.shadcn.com/) - Beautifully designed components built with Radix UI and Tailwind CSS
- [Lucide](https://lucide.dev/) - Beautiful & consistent icon toolkit
- [React Router](https://reactrouter.com/) - Client-side routing for React
- [class-variance-authority](https://cva.style/) - A library for creating type-safe variants for your components
- [clsx](https://www.npmjs.com/package/clsx) - A tiny utility for constructing className strings conditionally
- [tailwind-merge](https://github.com/dcastil/tailwind-merge) - A utility function to merge Tailwind CSS classes without style conflicts

## Deployment

To deploy this project, follow these steps:

1. Build the project:
   ```bash
   npm run build
   ```

2. Deploy the contents of the `dist` directory to your preferred hosting service (Vercel, Netlify, etc.)
